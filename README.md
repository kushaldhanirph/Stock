# বাফেট-স্টাইল ভ্যালু স্টক স্ক্রিনার (ভারতীয় বাজার)

Warren Buffett-এর ভ্যালু ইনভেস্টিং নীতি অনুযায়ী NSE-এর স্টক অটোমেটিক স্ক্রিন ও র‍্যাঙ্ক করে এমন একটা ফ্রি ওয়েব অ্যাপ।

## এটা কী করে

- **yfinance** লাইব্রেরি দিয়ে প্রতিটা স্টকের লাইভ ফান্ডামেন্টাল ডেটা টানে (সম্পূর্ণ ফ্রি, কোনো API key লাগে না)
- ৬টা বাফেট-স্টাইল মানদণ্ডে প্রতিটা স্টককে ১০০-র মধ্যে স্কোর করে:
  - ROE (Return on Equity)
  - Debt-to-Equity
  - P/E Ratio
  - P/B Ratio
  - Free Cash Flow
  - Earnings Growth
- **Graham Number** ফর্মুলা দিয়ে Intrinsic Value বের করে এবং তার সাথে বর্তমান দামের তুলনা করে **Margin of Safety** দেখায়
- ফলাফল টেবিল আকারে সাজিয়ে সবচেয়ে "ভ্যালুয়েবল" স্টক উপরে দেখায়
- **প্রতি ১২ ঘণ্টায় ডেটা অটোমেটিক রিফ্রেশ** হয় (cache TTL দিয়ে) — চাইলে সাইডবার থেকে ম্যানুয়ালিও রিফ্রেশ করা যায়

## লোকালি চালানো

```bash
pip install -r requirements.txt
streamlit run app.py
```

ব্রাউজারে `http://localhost:8501` এ খুলবে।

## সম্পূর্ণ ফ্রি-তে অনলাইনে হোস্ট করবেন যেভাবে (Streamlit Community Cloud)

1. একটা ফ্রি GitHub অ্যাকাউন্ট বানান (না থাকলে) → github.com
2. এই ফোল্ডারের (`app.py`, `requirements.txt`) ফাইলগুলো একটা নতুন **public** GitHub repository-তে আপলোড করুন
3. https://share.streamlit.io এ যান, GitHub দিয়ে সাইন ইন করুন
4. "New app" ক্লিক করে আপনার repository ও `app.py` ফাইল সিলেক্ট করুন
5. Deploy চাপুন — কিছুক্ষণের মধ্যে আপনার অ্যাপ একটা পাবলিক লিংকে (যেমন `yourapp.streamlit.app`) লাইভ হয়ে যাবে

এটা সম্পূর্ণ ফ্রি (Streamlit Community Cloud-এর ফ্রি টায়ার), কোনো ক্রেডিট কার্ড লাগে না, এবং অ্যাপটা প্রতিদিন নিজে থেকেই সবার জন্য অ্যাক্সেসযোগ্য থাকবে।

## কাস্টমাইজ করবেন যেভাবে

- সাইডবারে টিকার লিস্ট এডিট করে যেকোনো NSE স্টক যোগ/বাদ দিতে পারবেন (ফরম্যাট: `TICKER.NS`)
- `app.py`-এর `score_stock()` ফাংশনে গিয়ে স্কোরিং-এর weight/thresholds বদলাতে পারবেন
- পুরো Nifty 500 লিস্ট চাইলে NSE-এর অফিসিয়াল CSV থেকে টিকার লিস্ট বানিয়ে সাইডবারে পেস্ট করে দিতে পারেন

## সীমাবদ্ধতা ও সতর্কতা

- yfinance মাঝে মাঝে rate-limit বা ডেটা মিসিং সমস্যা করতে পারে (ফ্রি সোর্স বলে) — কোড এমনভাবে লেখা যাতে সেসব ক্ষেত্রে স্কিপ করে এগিয়ে যায়
- Graham Number ও এই স্কোরিং একটা **সরলীকৃত মডেল**, পেশাদার ভ্যালুয়েশনের বিকল্প নয়
- এটা একটা **শিক্ষামূলক টুল**, বিনিয়োগ পরামর্শ (investment advice) নয়। আসল টাকা বিনিয়োগের আগে নিজে রিসার্চ করুন বা SEBI-নিবন্ধিত আর্থিক উপদেষ্টার সাথে কথা বলুন।
